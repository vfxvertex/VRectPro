VRectPro

Create rounded rectangles and polygons in After Effects, and change their size and corners with sliders.

Make a shape in one click, fit it to a layer or your whole comp, set its anchor point, and save looks as presets. Use Swap and Swapoly to convert shape layers you already have, with all their source properties kept.

Quick start

What you needAfter Effects 18.4 or newer, Windows or macOS. The Dark, Light and System panel themes need version 25.
  1. Install the extension (Install).
  2. Enter your Gumroad license key (Activate).
  3. Open Window > Extensions > VRectPro, open a comp and press Create.

Install the extension

Your download is VRectPro.zip. Unzip it and you will find com.vertex.vrectpro.zxp and an installation .txt file with the steps. Start with Method A. If your installer refuses the file, use Method B.

  1. Close After Effects.
  2. Unzip VRectPro.zip. Inside you get com.vertex.vrectpro.zxp and an installation .txt file you can follow too.
  3. Download and install the free aescripts + aeplugins ZXP Installer (Windows and macOS).
  4. Drag com.vertex.vrectpro.zxp into the installer window and wait for the success message.
  5. Open After Effects, then go to Window > Extensions > VRectPro.
  1. Close After Effects.
  2. Unzip VRectPro.zip. You get com.vertex.vrectpro.zxp and an installation .txt file.
  3. Rename com.vertex.vrectpro.zxp to com.vertex.vrectpro.zip. If you can’t see .zxp, turn on “file name extensions” first.
  4. Extract that zip. You get a folder with CSXS, client and other files inside.
  5. Copy that folder to Adobe’s extensions folder:

macOS:   /Library/Application Support/Adobe/CEP/extensions/
  6. If VRectPro is missing from the Extensions menu, switch on Adobe’s debug mode (CSXS.12 for After Effects 2025 and newer, CSXS.11 for 2022 to 2024):

Activate your license

  1. After you buy, Gumroad shows and emails your license key. Keep that email.
  2. Open VRectPro in After Effects. The activation screen appears first.
  3. Paste the key exactly as you received it, with no extra spaces, and press Activate.
  4. The full panel opens. You won’t need to activate again on that computer.

Make your first shape

Open a composition first.

  1. Pick a preset from the list. Default is a good start.
  2. Press Create. A new rounded rectangle appears in your comp.
  3. Select the layer and open Effect Controls. Change Width, Height and Corner Radius.
  4. Click a square in the 3×3 grid to set the anchor point.
  5. Press Save preset to keep the look for later.

Swap and Swapoly

Turn shape layers you already have into VRectPro shapes. Select one or more layers and press the button.

ButtonWhat it does
SwapConverts a rectangle or rounded rectangle into a VRectPro shape.
SwapolyConverts a polygon into a VRectPoly shape. Hold ⇧ Shift to add a Fix Null on each corner.

The new shape keeps all properties from the source layer. The original layer is turned off and stays in your comp, right under the new one.

Layers that can’t be converted are skipped. The message after the button tells you how many.

Use Ctrl/Cmd+ZIf you don’t like the result, undo it.

Create modes: Selection, Matte and BG

Turn on a mode, then press Create. A mode stays on until you click it again.

ModeWhat you get
SelectionA shape the size of the selected layer, placed under it and linked to it so they move together. Good for a button behind text.
MatteSame as Selection, and the shape also masks the layer. Good for rounded corners on a video or screenshot.
BGA shape the size of your whole comp. Good for a background.

Anchor grid and nulls

The 3×3 grid sets where the anchor point sits on your shape. The lit square shows the current anchor and changes when you select another layer. It also works on layers that aren’t VRectPro shapes.

On a grid squareYou get
ClickThe anchor point moves there.
⇧ Shift + clickA Fix Null at that point. Parent another layer to it to keep it attached to that corner.
⌥ Alt/Option + clickA Control Null at that point. Move this null to move the shape.

Presets and defaults

ButtonWhat it does
Save presetSaves the selected shape under a name. It asks before replacing a name you already use.
Set defaultMakes the selected shape’s look the starting point for new shapes.
ResetGoes back to the built-in default look.
LibraryOpens the preset manager. Rename, reorder or delete presets, then press Save changes.
RemoveKeeps the shape as it is and removes the VRectPro controls.

In the preset list, drag a preset to reorder it, and right-click it to rename or delete. Default can’t be moved or deleted.

Good to know

  • To move a VRectPro shape, move its Control Null instead of changing the layer’s Position.
  • Set the anchor point with the grid, not by dragging it.
  • Remove can’t be undone from the panel. Use it when you’re happy with the shape.
  • If Create makes the wrong thing, check whether Selection, Matte or BG is still on.
  • Your license key works on two computers. Keep it private.

Troubleshooting

VRectPro isn’t in Window > Extensions
Restart After Effects. If you installed with the ZIP method, turn on debug mode (step 5 of Method B) and restart again.
The panel is blank or says “Loading…”
Turn on Allow Scripts to Write Files and Access Network in After Effects settings, then close and reopen the panel.
A button does nothing, or I see “Script error”
Make sure a comp is open. For Selection, Matte, Swap and Swapoly, make sure the right layer is selected.
Some layers weren’t swapped
Layers that can’t be converted are skipped. The message after Swap or Swapoly shows how many.
Presets won’t save
Update After Effects, turn on Allow Scripts to Write Files and Access Network, and make sure the name isn’t empty.
My license key says invalid
Copy it again from the Gumroad email with no spaces. If it says the limit is reached, two computers already use it. Contact support (@VfxVertex) to free a slot.
Dark, Light and System themes are missing
They need After Effects 25 or newer. Older versions use Darkest.
